# Baldev Ghataliya — Hacker Portfolio

Open `index.html` in a modern browser.

## Included
- Hacker / terminal-inspired responsive design
- Matrix-style animated background
- Experience, skills and project sections
- Responsive mobile navigation
- Scroll reveal animations
- Copy-email interaction
- **Send Message** form using `mailto:` to open the visitor's default email client

## Important
The site currently uses `hello@baldev.dev` as a placeholder destination. Replace this address in:
- `index.html`
- `js/script.js`

The Projects section contains explicitly marked illustrative/demo projects. Replace those with real project details when ready.

No backend is required for the current mail form. It opens the visitor's configured email application with the name, email, subject and message filled in.

If you want true server-side sending without opening an email client, a backend or form service will be needed.
